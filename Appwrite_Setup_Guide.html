2. هيكلة الجداول (Collections Setup)

يجب إنشاء المجموعات (Collections) التالية داخل قاعدة البيانات في Appwrite Console مع إضافة الحقول (Attributes) المذكورة:

أ. مجموعة المرضى (patients)

الحقل (Attribute)النوع (Type)الوصف
nameStringاسم المريض الكامل
titleStringعنوان المريض (يستخدم للبحث والمطابقة)
dateOfBirthStringتاريخ ميلاد المريض
phoneStringرقم هاتف المريض للتواصل
userIdStringالمعرف الفريد للمريض

ب. مجموعة الأدوية (medications)

الحقل (Attribute)النوع (Type)الوصف
nameStringاسم الدواء
dosageStringالجرعة (مثلاً: حبة واحدة)
timeStringوقت التنبيه (مثلاً: 08:00)
photoUrlString (URL)رابط صورة الدواء المخزنة
patientIdStringمعرف المريض التابع له هذا الدواء

ج. مجموعة المستخدمين (users)

الحقل (Attribute)النوع (Type)الوصف
nameStringاسم صاحب الحساب
phoneStringرقم الهاتف (يستخدم لتسجيل الدخول)
passwordStringكلمة المرور المشفرة
emailStringالبريد الإلكتروني

3. إعدادات الأمان (Permissions)

لكل مجموعة (Collection)، يجب الذهاب إلى تبويب **Settings** ثم **Permissions** وإضافة الصلاحيات التالية:
  • إضافة الدور: Any
  • تفعيل الخيارات: **Create, Read, Update, Delete** (للسماح للتطبيق بإدارة البيانات).

4. إعداد مخزن الصور (Storage)

في قسم **Storage**، يجب إنشاء Bucket بالمعرف التالي لرفع صور الأدوية:
Bucket ID: 690c619f003dcfb4358a
تأكد من جعل الـ Permissions للـ Bucket هي Any مع تفعيل **Read** و **Write**.

5. الكود البرمجي الرئيسي للاتصال

هذا الجزء من الكود يقوم ببناء الطلب وإرساله للسيرفر باستخدام HttpURLConnection:
URL url = new URL(BASE_URL + "/databases/" + MAIN_DATABASE_ID + "/collections/" + coll + "/documents"); HttpURLConnection connection = (HttpURLConnection) url.openConnection(); connection.setRequestMethod("POST"); // أو GET بجلب البيانات connection.setRequestProperty("X-Appwrite-Project", PROJECT_ID); connection.setRequestProperty("X-Appwrite-Key", API_KEY); connection.setRequestProperty("Content-Type", "application/json");
