بنية وهيكلية مشروع (DragApp)

التنظيم المجمّدي والتقني لتطبيق منبه الأدوية

1. الهيكل الشجري للمجلدات (Project Tree)

DragApp (الرئيسي) ├── app (وحدة التطبيق) │ ├── src/main │ │ ├── java/com/example/dragapp │ │ │ ├── DALAppWriteConnection.java (طبقة البيانات) │ │ │ ├── MainActivity.java (النشاط الرئيسي) │ │ │ ├── model/ (النماذج) │ │ │ │ ├── User.java │ │ │ │ └── Medication.java │ │ │ └── ui/ (واجهات التحكم) │ │ │ ├── HomeFragment.java │ │ │ ├── RemindersFragment.java │ │ │ ├── ProfileFragment.java │ │ │ ├── AddPatientFragment.java │ │ │ └── AddMedicationFragment.java │ │ ├── res/ (الموارد) │ │ │ ├── layout/ (تصاميم XML) │ │ │ ├── values/ (نصوص وألوان) │ │ │ └── drawable/ (أيقونات وصور) │ │ └── AndroidManifest.xml (الأذونات) └── gradle/ (إعدادات البناء والمكتبات)

2. شرح المكونات الوظيفية

  • حزمة النماذج (Model Package): تحتوي على كلاسات تمثل جداول قاعدة البيانات، وظيفتها تحويل البيانات القادمة من السيرفر إلى كائنات (Objects) يسهل التعامل معها داخل التطبيق.
  • حزمة الواجهات (UI Package): تحتوي على جميع الـ Fragments المسؤولة عن شكل وتفاعل الصفحات، مما يوفر سرعة في التنقل واستهلاكاً أقل لذاكرة الهاتف.
  • طبقة الوصول للبيانات (DAL): هي صلة الوصل الوحيدة بالسيرفر؛ حيث يتم فيها تجميع كافة أوامر الاتصال بـ Appwrite لضمان أمان وتنظيم العمليات البرمجية.
  • الموارد (Resources): تم فصل التصميم (XML) والألوان والنصوص تماماً عن الكود البرمجي لسهولة التعديل والتطوير المستقبلي.
